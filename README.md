# Correlação Canônica (CCA)

Repositório de códigos de apoio à **Análise de Correlação Canônica (Canonical Correlation Analysis — CCA)**.

## Objetivo

Investigar associações lineares entre dois conjuntos de variáveis, construindo combinações que maximizam a correlação entre os conjuntos.

## Roteiro metodológico

- Identificar e preparar os dois blocos de variáveis.
- Avaliar escalas, multicolinearidade e observações influentes.
- Estimar pares de variáveis canônicas.
- Examinar correlações canônicas, cargas e redundância.
- Interpretar os resultados à luz do desenho amostral.

Este é um repositório de apoio acadêmico. Consulte os arquivos-fonte para identificar as análises implementadas.
